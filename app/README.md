# 1С Lab: ИИ под проверкой

Электронный образовательный ресурс (тренажёр) для специальности 09.02.11, дисциплина ОП.13 «Автоматизация бизнес-процессов»: студент проверяет схему бизнес-процесса, расчёт окупаемости, запрос и код на языке 1С — всё «сгенерированное ИИ» и содержащее реальные ошибки, которые нужно найти и исправить.

Реализация — React + Vite, порт визуального прототипа из `../project/1C Lab.dc.html` (хэндофф из Claude Design, спецификация — `../project/DESIGN_SPEC.md`).

## Шаги

- **Шаг 1 · Теория** — шесть карточек про ИИ-инструменты в задачах 1С и их ловушки + квиз на 3 вопроса с мгновенной проверкой.
- **Шаг 2 · Практика** — четыре задания с настоящей логикой проверки:
  - «Разрывы в схеме процесса» — клики по проблемным шагам схемы согласования закупки сверяются с картой из 5 реальных разрывов.
  - «Расчёт окупаемости» — экономия времени/денег и срок окупаемости считаются из введённых чисел.
  - «Запрос на языке 1С» — правки в запросе проверяются регулярками (SELECT *, ЛЕВОЕ СОЕДИНЕНИЕ, отбор по параметру, параметр виртуальной таблицы).
  - «До / После» — два статичных столбца сравнивают ручной процесс и доработку в 1С.
- **Шаг 3 · Проект** — сборка постановки задачи из проверяемых требований, чек-лист приёмки на 10 пунктов, рефлексия (для педагога).

Прогресс (выполненные задания, чек-лист, выбранные требования, рефлексия, тема, размер шрифта) сохраняется в `localStorage`; ответы квиза, найденные разрывы, цифры расчёта и текст запроса — не сохраняются (задания перепроходятся с нуля). Бэкенда нет — всё считается в браузере.

## Разработка

```bash
npm install
npm run dev      # локальный сервер с HMR
npm run build    # production-сборка в dist/
npm run preview  # предпросмотр собранной версии
```

Деплой на GitHub Pages происходит автоматически при пуше в `main` (см. `../.github/workflows/deploy.yml`).
