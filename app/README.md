# UI/UX Lab: ИИ под проверкой

Электронный образовательный ресурс (тренажёр-детектив) для специальности 09.02.11: студент оценивает интерфейсы и код, «сгенерированные ИИ», и находит, что именно упущено с точки зрения юзабилити, доступности и корректности.

Реализация — React + Vite, порт визуального прототипа из `../project/UI-UX Lab.dc.html` (хэндофф из Claude Design, см. `../README.md` и `../chats/`).

## Уровни

- **Уровень 1 · Стажёр** — шесть карточек про ИИ-инструменты и их ловушки + квиз с мгновенной проверкой.
- **Уровень 2 · Джуниор** — четыре кейса с настоящей логикой проверки:
  - «Найди баг юзабилити» — клики по проблемным зонам в реальной форме сверяются с картой известных проблем.
  - «Замер вместо угадайки» — контраст считается по формуле WCAG 2.1 из введённых HEX-цветов.
  - «Почини код» — правки в сниппете проверяются регулярками (alt, type="email", label, адаптивная сетка).
  - «До / После» — слайдер-компаратор сырого и доработанного варианта.
- **Уровень 3 · Мидл** — сборка промпта-ТЗ из проверяемых требований, чек-лист по 10 эвристикам Нильсена, рефлексия (для педагога).

Прогресс, тема и размер шрифта сохраняются в `localStorage`. Бэкенда нет — всё считается в браузере.

## Разработка

```bash
npm install
npm run dev      # локальный сервер с HMR
npm run build    # production-сборка в dist/
npm run preview  # предпросмотр собранной версии
```
